E-REDES → Home Assistant

  1. Cada Home Assistant mostra o caminho do seu webhook numa notificação quando adicionas a integração E-REDES.
  2. Junta cada caminho ao endereço do respetivo HA e cola um por linha. Ao guardar, o browser pede autorização para cada endereço.
  3. Depois basta fazeres login no Balcão Digital: o token é enviado para todos.
